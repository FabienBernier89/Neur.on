What the review editor does, exactly

A CAT tool splits the document into segments. A segment is a sentence or a heading. You review each segment against its original, correct it if needed, then confirm it.

The editor opens from the project dashboard, with the Open in CAT button. Everything below was observed in the application.

Create the project: Translation projects Check a term: Fast lookup CHnell
Two columns

The original on the left, the translation on the right, segment by segment. A search filter above each column finds a sentence on the source or translation side.

Origin of each sentence

An indicator shows whether the translation comes from the engine or from the translation memory. For machine translation, a gauge gives the quality level: low, medium or high.The translation memory holds translations that have already been approved.

Confirmation

One checkbox per segment confirms its review. The document's progress is shown as a percentage at the top of the editor.

Toolbar

Formatting tags (opening, closing, standalone), bold, italic, underline, and copying the source into the translation.Tags mark the formatting of the original document.

Checks

The editor flags repeated sentences and inconsistent tags.

Memories

For the selected sentence, the closest translations already approved. Click Apply to use one in the translation.

Fast Lookup

Live search in your memories and in CHnell, on the source or target side. Each result is bilingual, the term is highlighted on both sides and the original document is shown.

AI assistant

Alternatives: the same sentence translated by several engines, side by side, with more on request. Rephrasing: a rewording in five styles (formal legal, financial, simplified, formal, informal), with an option to shorten.Words changed by the rephrasing are underlined.

Sync

For review by several people: conflicts between two versions to resolve, a colleague's changes to merge, and propagation of a correction to identical sentences.

Dashboard

Confidentiality, review type, languages, progress, reference files, instructions, memories and team. For each file: Open in CAT, Preview, Export docx, Reimport docx, Download TMX and Validate.TMX is the standard exchange format for translation memories.

Do your corrections carry over to your next translations?

Yes, with standard confidentiality. Each correction made in the editor is kept in your translation memory. In the next project, Corrext reuses it. Project after project, the translation adapts to the way you write. And the same passage is translated the same way from one project to the next.

One deliberate exception: in Highly sensitive content mode, translations do not feed the memory. The data is then stored and processed in Switzerland only. This mode is available in German, French, Italian and English.

Frequently asked questions about the review editor

What is a CAT tool?

CAT stands for computer-assisted translation. A CAT tool splits the document into segments, that is, sentences or headings, and places each one next to its translation. The reviewer corrects and then confirms each segment, with the help of translation memories and terminology. In Corrext, this tool is called the review editor.

How do I open the review editor?

From a project dashboard. Each file there has an Open in CAT button, which opens the document in the editor. The project itself is created in Translation projects: languages, confidentiality level, terminology and translation engine.

Are my corrections used in future translations?

Yes, with standard confidentiality. Your projects are stored on Corrext's Swiss servers and serve as a translation memory for you alone. A correction made today is reused in your next projects. The translation adapts to your language and stays consistent from one project to the next.

And in Highly sensitive mode?

In Highly sensitive content mode, translations do not feed the memory. The data is stored and processed in Switzerland only. The mode is available in German, French, Italian and English. You choose it when you create each project.

Can several people review the same document?

Yes. The Sync tab handles work by several reviewers. It shows conflicts between two versions of the same sentence, for you to resolve. It lists a colleague's changes, for you to merge. Finally, it offers to apply a correction to the identical sentences in the document: this is propagation. The project team is managed from the dashboard.

Do I need Microsoft Word to review?

No. The review editor works directly in Corrext. If you prefer Word, export the document from the dashboard (Export docx), review it with the Corrext add-in, then reimport it (Reimport docx). The add-in requires a sign-in, project membership and Office 2021 or Microsoft 365.

Are the terms I set respected?

Yes. When the project is created, Corrext itself extracts candidate terms from the document. You set their translation, or add your own terms. A term you have set is used as it is in the machine translation, which you then review in the editor.

Which file formats can I review?

Those you upload to a project: .pdf, .doc, .docx, .xls, .xlsx, .ppt and .pptx, up to 50 MB per file. The application recommends the original format rather than PDF. From the dashboard, the reviewed document is exported to Word, and its memory can be downloaded in TMX format, the standard exchange format for translation memories.
