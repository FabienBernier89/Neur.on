Dépannage

Pourquoi le bouton Next reste-t-il grisé ?

Dans Gestion de projet, le bouton « Next » ne s'active que lorsque l'étape en cours est complète. À l'étape « Set-up », il reste grisé tant qu'aucune langue cible n'a été sélectionnée. À l'étape « File overview », il reste grisé tant qu'aucun fichier n'a été déposé. À l'étape « Quotes », le bouton « Generate quote » suit la même logique et attend une échéance et un niveau de relecture.

  1. À l'étape « Set-up », cliquez sur « Select target languages » et cochez au moins une langue cible.
  2. Vérifiez que la puce de langue s'affiche bien sous le bouton : c'est elle qui active « Next ».
  3. À l'étape « File overview », déposez au moins un fichier dans la zone prévue avant de chercher « Next ».
  4. À l'étape « Quotes », renseignez une échéance dans « Due date » et un niveau dans « Review level ».
  5. Vérifiez alors que le bouton « Generate quote » est devenu actif.
À savoir
  • Un bouton grisé dans Corrext signale une information manquante, pas une panne : l'écran attend toujours une donnée précise.
  • Si la langue voulue n'apparaît pas dans la liste, vérifiez le niveau de confidentialité choisi à l'étape précédente.
  • Le projet est créé dès le passage à l'étape « File overview » : vous n'avez donc pas à recommencer le réglage initial.
Pourquoi ma langue cible n'est-elle pas disponible ?

Si une langue cible n'apparaît pas dans la liste, la cause la plus fréquente est le mode « Highly sensitive content ». Ce mode impose un traitement exclusivement suisse et n'est disponible que pour l'anglais, le français, l'italien et l'allemand. En le désactivant, ou en choisissant la confidentialité standard dans un projet, vous retrouvez les 30 langues de la plateforme.

  1. Dans Traduction texte et document, repérez l'interrupteur « Highly sensitive content » à droite des onglets et vérifiez s'il est actif.
  2. Désactivez-le si votre contenu le permet : la liste des langues cibles se recharge avec les 30 langues.
  3. Dans un projet, revenez à l'étape « Set-up » et vérifiez la carte de confidentialité sélectionnée.
  4. Choisissez « Standard confidentiality » si le document n'exige pas un traitement exclusivement suisse.
  5. Si le contenu est confidentiel, conservez le mode sensible et retenez une des quatre langues disponibles.
À savoir
  • Le choix entre confidentialité et étendue linguistique est explicite dans l'application : la carte du mode sensible annonce elle-même ses quatre langues.
  • Utilisez le champ de recherche de la liste de langues avant de conclure à une absence : la liste est longue.
  • Une langue absente n'a rien à voir avec le moteur choisi : c'est le mode de confidentialité qui restreint la liste.
Pourquoi la traduction ne se lance-t-elle pas ?

Dans l'onglet « Text translation », il n'existe pas de bouton pour lancer la traduction : elle se fait au fil de la saisie. Si rien n'apparaît dans le volet de droite, vérifiez d'abord que la langue source et la langue cible sont différentes, car l'application affiche alors le message « Identical source and target languages ». Un message d'erreur passager peut aussi s'afficher : relancez l'action.

  1. Vérifiez que du texte est bien présent dans le volet de gauche et que le compteur de caractères n'est pas à zéro.
  2. Comparez les deux listes de langues : si elles sont identiques, le volet cible affiche « Identical source and target languages ».
  3. Changez la langue cible, ou utilisez le bouton d'inversion entre les deux listes.
  4. Vérifiez que vous n'avez pas dépassé la limite de caractères de l'onglet en cours.
  5. Si un message d'erreur passager apparaît, relancez l'action : le panneau se charge généralement à la seconde tentative.
  6. Dans CHnell, souvenez-vous que la touche Entrée ne lance pas la recherche : utilisez le bouton « Search ».
À savoir
  • L'absence de bouton de validation est voulue : la traduction se recalcule à chaque modification du texte source.
  • Le bouton de régénération de l'onglet « Rephrasing » sert précisément à redemander un résultat quand le premier ne convient pas.
  • Une même phrase peut renvoyer un résultat identique après régénération : c'est le comportement observé, passez alors par le panneau « Alternatives ».
Pourquoi mon fichier est-il refusé ?

Un fichier refusé par Corrext tient presque toujours à l'une de trois causes : un format hors de la liste acceptée, un poids supérieur à 50 Mo, ou un envoi de plus de 25 fichiers en une fois. L'onglet « PDF to Word » ajoute une contrainte propre, puisqu'il n'accepte que le format .pdf. Les zones de dépôt rappellent ces limites à l'écran, juste sous le bouton d'envoi.

  1. Vérifiez l'extension : seuls .pdf, .doc, .docx, .xls, .xlsx, .ppt et .pptx sont acceptés pour la traduction.
  2. Vérifiez que vous n'êtes pas sur l'onglet « PDF to Word », qui n'accepte que le format .pdf.
  3. Vérifiez le poids du fichier : la limite est de 50 Mo par fichier.
  4. Comptez les fichiers de votre lot : la limite est de 25 fichiers par envoi.
  5. Repartez du fichier d'origine, .docx ou .xlsx plutôt qu'un PDF : il est souvent plus léger et mieux traité.
  6. Relisez le texte de la zone de dépôt, qui affiche la liste exacte des formats et la taille maximale autorisée.
À savoir
  • Le format et le poids se vérifient plus vite que le contenu : commencez toujours par ces deux points.
  • Un PDF scanné très lourd gagne à être converti en Word par l'onglet « PDF to Word » avant toute autre opération.
  • Les limites sont identiques dans Traduction texte et document et dans Gestion de projet : un fichier refusé d'un côté le sera de l'autre.
