Review editor

The review editor opens from a project with ‘Open in CAT’. You review segment by segment, with translation memory, CHnell and the alternatives to hand, then you validate the file and download it.

How do I review a file in the editor?

On the project dashboard, the ‘Open in CAT’ button opens the review editor. The document is shown in two columns, source text on the left and translation on the right, sentence by sentence. You correct the translation in the right-hand column, confirm each sentence you have reviewed and use the side panel for help: memories, Fast Lookup, AI assistant and Sync.

  1. Open the project from ‘My projects’ on the home page, then find the file's row in the task table.
  2. Click Open in CAT: the editor opens on the translated document.
  3. Find a word with Filter source or Filter target.
  4. Click a sentence: the side panel shows the memory matches and the AI assistant's alternatives.
  5. Correct the translation in the right-hand column, then tick the sentence's box to confirm it.
  6. Follow the progress as a percentage at the top of the editor, then go back to the dashboard with Back.
Good to know
  • The ‘MT’ marker shows a sentence produced by machine translation. Its gauge gives an indication of quality.
  • Repeated sentences and tags that do not match between source and translation are flagged in the table.
  • With standard confidentiality, your corrections enrich your translation memory and are used in your next projects.
What is the editor's side panel for?

The editor's side panel brings together four tools, available from the icons on the right of the screen: translation memories, Fast Lookup, the AI assistant and Sync. They work on the selected sentence and change nothing until you click ‘Apply’.

  1. Select a sentence in the editor.
  2. Translation memories tab: look up previously validated translations close to the sentence, and apply one with ‘Apply’.
  3. Fast Lookup tab: search for a word in the memories and in CHnell, on the ‘Source’ or the ‘Target’ side.
  4. AI Assistant tab, ‘Alternatives’ section: compare the sentence as translated by several engines, and get more with ‘Generate more’.
  5. Rephrasing section: choose a style in ‘Settings’ (Formal legal, Financial, Simplified, Formal, Informal) or the ‘Shorten’ option, then click ‘Apply’.
  6. Sync tab: resolve version conflicts and decide on propagation.
Good to know
  • In Fast Lookup, the term you search for is highlighted in the source and in the translation, with the name of the original document.
  • Rephrasing underlines the words it changes: you see the difference before you apply it.
  • Sync is only useful if several people are working on the same file, or if you have opened it in several sessions.
Are my corrections used in future translations?

Yes, with Standard confidentiality. The segments you correct and confirm in the editor enrich your organisation's translation memory. Corrext then suggests these matches for similar sentences in later projects: the translation gradually adapts to your vocabulary. In Highly sensitive content mode, nothing is reused.

Good to know
  • Memory matches appear in the ‘Translation memories’ tab of the side panel, with an ‘Apply’ button.
  • The memory is used exclusively by your organisation.
How do I review a translation in Word?

If you prefer to review in Word, export the file from the dashboard with ‘Export docx’, open it in Word and display the Corrext add-in from the ribbon. Its panel includes the AI assistant, Fast Lookup, memory matches and Sync. When you have finished reviewing, reimport the file into the project with ‘Reimport docx’.

  1. On the project dashboard, click Export docx for the file you want to review.
  2. Open the exported file in Word, then click the Corrext button on the ribbon to display the ‘Corrext editor’ panel.
  3. Click Log in if the panel asks you to sign in.
  4. Review with the help of the ‘AI Assistant’, ‘Fast Lookup’, ‘Matches’ and ‘Sync’ tabs.
  5. Save the document, then reimport it into the project with Reimport docx.
Good to know
  • The add-in only opens on a document exported with ‘Export docx’: a file from fast translation is rejected.
  • You must be a member of the project and have Word 2021 or Microsoft 365.
  • While a long document is loading, do not close the panel or the file. You can already start working, then resolve conflicts in ‘Sync’.
How do I validate and download the translation?

When the review is finished, the ‘Validate’ button on the dashboard closes the task: this action is final. The dashboard also offers a preview of the file (‘Preview’), the Word export and a download of the project memory in TMX format.

  1. Check the progress shown in the editor, then go back to the dashboard.
  2. Check how the file looks with Preview.
  3. Click Validate below the task's ‘Reviewing’ status, then confirm.
  4. To close all the tasks at once, use Validate all.
  5. Download the translation and, if needed, the project memory with Download TMX.
Good to know
  • Validation cannot be undone: Corrext reminds you of this in the confirmation window.
  • A task goes through the statuses ‘Reviewing’, ‘Validated’ and then ‘Exported’ once the Word file has been exported.
  • TMX is the standard exchange format for translation memories: you can reuse it in most translation tools.
